## 바로 확인할 경로

Jarvis에서 **테스트 실행**으로 자동 검사 결과를 확인한다. 화면은 **화면 준비 → 이 PC에서 화면 열기**로 연다. 사용 중인 PC에서 개발 도구 설치나 터미널 설정을 할 필요는 없다. 이번 점검에서 화면 링크를 발급하거나 화면을 검증하지는 않았다.

화면 확인 순서:

1. 첫 안내와 상품 카드가 보이는지 확인한다. 더미 상품은 20개다.
2. 상품을 보관·보류·삭제하고 새로고침 후 상태가 유지되는지 확인한다. 테스트용 브라우저 데이터를 사용한다.
3. 보관함에서 코디를 열어 상의·하의 교체, 원피스와 아우터 조합, 구매 정보 열기·닫기를 확인한다.
4. 실제 Safari 검증은 별도 결과로 기록한다. 현재 E2E 설정은 Edge(Chromium)이며 iPhone 사용자 에이전트를 사용해도 Safari 엔진 검증이 되지는 않는다.
