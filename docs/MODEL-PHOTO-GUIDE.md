# 모델 사진 촬영 가이드

가상 피팅 레이어는 **모델 사진 한 장 위에 옷만 오려 붙이는 방식**이다. 그래서 모델 사진의 품질과 포즈가 결과를 거의 결정한다.
맥미니 시험에서 확인된 사실:

- 거울 셀카(폰 든 손이 가슴을 가림) → 결과 엉망 (mac-test3)
- 정면 전신, 손이 몸을 안 가림 → 깔끔 (mac-test4·5)
- 모델이 원래 입은 옷이 새 옷보다 길거나 크면, 그 부분이 새 옷 밖으로 비친다 (mac-test3의 허리 핑크 띠)

모든 모델은 아래 **같은 조건**으로 찍는다. 체형 그룹끼리 레이어를 옮겨 쓰려면(다음 단계) 촬영 조건이 같아야 한다.

---

## 1. 반드시 지킬 것 (어기면 자동 검사에서 불합격 → 생성 안 함)

| 항목 | 기준 |
|---|---|
| 전신 | 머리 끝부터 발끝까지 전부 화면 안에. 발목이 잘리면 불합격 |
| 서 있기 | 똑바로 선 자세. 앉기·기대기·한쪽 무릎 굽히기 금지 |
| 정면 | 몸과 얼굴 모두 카메라 정면. 어깨선이 수평(기울기 10° 이내) |
| 두 눈 | 두 눈이 모두 보일 것 (머리카락·손·폰으로 가리지 않기) |
| 손·팔 | 손·손목·팔꿈치·아래팔이 **가슴·배 앞을 지나가지 않을 것**. 폰 들기, 팔짱, 허리에 손 얹기 금지 |
| 셀카 금지 | 거울 셀카·폰 들고 찍기 금지. 다른 사람이 찍거나 삼각대 + 타이머 |

## 2. 표준 포즈 (A포즈)

```
        O
      / | \        ← 팔을 몸통에서 주먹 하나 정도(약 10~15°) 바깥으로
     /  |  \
        |          ← 손바닥은 허벅지 쪽, 손가락은 자연스럽게 폄
       / \
      /   \        ← 발은 골반 너비, 발끝은 정면
```

- 팔을 몸에 딱 붙이면 **주의** (생성은 됨). 옷 옆선과 팔 경계가 뭉개질 수 있다.
- 팔을 너무 벌리면(30° 이상) 소매 모양이 어색해진다. 살짝만.
- 시선은 카메라, 표정은 무표정이나 살짝 미소. 고개 숙이거나 돌리지 않기.

## 3. 모델이 입을 옷 (중요)

새 옷이 원래 옷보다 작으면 원래 옷이 비치므로, **몸에 붙고 짧은 기본 옷**을 입힌다.

- 상의: 몸에 붙는 **민소매(나시) 또는 끈 탑**. 반팔 티 금지(소매가 비침), 크롭 길이면 더 좋음
- 하의: 몸에 붙는 **짧은 바이커 쇼츠·레깅스 반바지**. 긴 바지·치마 금지
- 색: **무지 연회색 또는 베이지**. 피부·배경과 구분되는 색. 무늬·로고·흰색·검정 피하기
- 액세서리 없이: 가방, 시계, 목걸이, 모자, 안경 모두 빼기 (얼굴·머리처럼 "보호 영역"이 되어 옷이 그 위를 못 덮는다)
- 머리: **묶거나 어깨 뒤로**. 어깨·가슴 위로 내린 머리는 옷이 덮지 못한다
- 신발: 모든 모델 같은 신발(예: 흰 운동화) 또는 맨발로 통일

## 4. 촬영 세팅 (모든 모델 동일하게)

| 항목 | 기준 |
|---|---|
| 배경 | 흰색·연회색 단색 벽 또는 배경지. 가구·문·거울 없이. 모델은 벽에서 1m 이상 떨어져 그림자가 벽에 안 지게 |
| 조명 | 고르게 밝게. 창가 직사광선·한쪽만 센 조명 금지 (강한 그림자 = 옷 경계 오류) |
| 카메라 높이 | 렌즈를 모델 **배꼽 높이**에. 위·아래에서 찍으면 다리 길이·몸 비율이 바뀐다 |
| 거리 | 약 3m. 폰 기본 1배 렌즈(광각 0.5배 금지) |
| 구도 | 세로 사진. 머리~발목이 화면 높이의 70~95%, 사람이 가로 가운데 |
| 고정 | 삼각대 사용. 바닥에 테이프로 **발 위치**와 **삼각대 위치**를 표시해 두고 모든 모델을 같은 자리에서 |
| 해상도 | 세로 1280px 이상 (폰 기본 사진이면 충분) |
| 파일 | PNG 또는 JPG 원본. 보정·필터·뷰티 효과 끄기 |

## 5. 찍은 뒤 자동 검사

사진을 `factory/in-sample/` 에 넣고:

```bash
cd ~/viet/factory && .venv/bin/python pose_check.py in-sample/m01.png in-sample/m02.png
```

- 사진마다 **통과 / 주의 / 불합격**과 이유가 나온다.
- `factory/out/pose-check/` 에 관절점과 몸통 사각형을 그린 확인용 이미지가 저장된다. 노란 사각형(몸통) 안으로 손·팔이 들어오면 불합격.
- 착용 생성(`make_layers.py`)도 시작 전에 같은 검사를 하고, 불합격이면 생성하지 않는다.

### 불합격·주의 메시지별 해결

| 메시지 | 다시 찍는 법 |
|---|---|
| 전신이 아님 | 카메라를 뒤로 물리거나 위아래 여백 늘리기 |
| 서 있는 자세가 아님 | 똑바로 서서 무릎 펴기 |
| 어깨선이 기울어짐 | 한쪽 다리에 체중 싣지 말고 양발에 고르게 |
| 정면이 아님 / 얼굴이 옆을 봄 | 발끝·배꼽·코가 카메라를 향하게 |
| 두 눈이 다 보이지 않음 | 머리카락 넘기기, 고개 들기 |
| ○팔이 상체를 가림 | 손을 몸 옆으로 내리기 (폰·가방 내려놓기) |
| ○팔이 몸에 붙음 (주의) | 팔을 주먹 하나만큼 바깥으로 |
| 사람 크기가 표준과 다름 (주의) | 바닥 테이프 위치에서 다시 |
| 배경이 단색이 아님 (주의) | 단색 벽 앞에서, 가구가 안 걸리게 |

## 6. 체형 그룹 (레이어 재사용 준비)

- 체형이 비슷한 모델끼리 그룹을 만들고(예: S·M·L), 그룹마다 **대표 모델 1명**을 정한다.
- AI 착용은 대표 모델에만 하고, 같은 그룹의 다른 모델에는 레이어를 옮겨 얹는다. 촬영 조건이 다르면 옮긴 옷이 어긋난다.
- 체형 차이가 크면 대표 모델의 옷 주름·그림자가 어색하게 남으므로 그룹을 잘게 나눈다.
